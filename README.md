# Gerador de Senhas

Aplicação desenvolvida com o objetivo de gerar senhas seguras e aleatórias para utilização em sistemas, plataformas e serviços que exigem diferentes critérios de segurança.

## Tecnologias

* Python

## Funcionalidades

* Geração automática de senhas
* Combinação de letras maiúsculas e minúsculas
* Inclusão de números
* Inclusão de caracteres especiais
* Criação de senhas mais seguras para diferentes plataformas

## Exemplos de utilização

* Contas de e-mail
* Sistemas corporativos
* Plataformas bancárias
* Serviços governamentais como o Gov.br
* Redes sociais e aplicações web

## Objetivo

Projeto criado para praticar lógica de programação, manipulação de caracteres e desenvolvimento de aplicações voltadas para segurança e utilidade no dia a dia.
